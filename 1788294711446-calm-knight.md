## Fase 3 — Prompt 02: Modelo

### 3.1 `src/ml/12-modelo.py`
Notebook Python para serverless:

1. **Baseline** — holdout 25% (random_state=42, estratificado). AUC de 3 regras simples + moeda
2. **Treino** — `HistGradientBoostingClassifier` (sklearn). NÃO XGBoost
3. **Métricas** — `auc` (holdout) + `lift_top200` (CV out-of-fold 5 folds) + `acertos_top200`
4. **Importância por permutação** — holdout, n_repeats=5, top 10
5. **MLflow** — `mkdirs` antes de `set_experiment`. Log em `lakehouse_rotaperfume.gold.propensao_compra` com alias `@prod`
6. **3 asserts** — modelo ganha baseline por ≥0.05 AUC; auc < 0.99; lift_top200 ≥ 2.5
7. **Score** — `mlflow.sklearn.load_model`, `predict_proba`, pandas. Grava `gold.score_propensao` com faixa NTILE(4)
8. **Tabelas** — `gold.modelo_metricas` + `gold.calibragem_holdout`

### 3.2 Atualizar `pipeline.job.yml`
- Task `ml_modelo` → depende de `ml_features`
